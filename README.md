# Three-Tier-Campus-Enterprise-Network-Designed-Built-in-Cisco-Packet-Tracer
A simulated two-office enterprise network built in Cisco Packet Tracer using a three-tier hierarchical model. Features VLSM, inter-VLAN routing, HSRP, OSPF, DHCP relay, wireless infrastructure, port security, SSH management, and ACL-based security policies.
